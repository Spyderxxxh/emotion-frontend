# 组件状态设计规范

## 🎯 状态设计原则

1. **清晰可辨**: 每个状态都应有明确的视觉差异
2. **即时反馈**: 用户操作后立即显示状态变化
3. **一致性**: 相同类型的组件使用相同的状态模式
4. **无障碍**: 不仅依赖颜色，使用图标、文字辅助

## 🖱️ 光标状态

```css
/* 可点击 */
.clickable {
  cursor: pointer;
}

/* 禁用 */
.disabled {
  cursor: not-allowed;
}

/* 文本选择 */
.selectable {
  cursor: text;
}

/* 可调整大小 */
.resizable {
  cursor: resize;
}

/* 加载中 */
.loading {
  cursor: wait;
}

/* 帮助 */
.help {
  cursor: help;
}
```

## ♿ 无障碍状态

### 焦点环

```
所有可交互元素必须有可见的焦点状态:

┌────────────────────────────┐
│                            │
│    按钮                    │  ← 2px 主色外框
│                            │     2px 偏移
└────────────────────────────┘

┌────────────────────────────┐
│  [输入内容]           │    │  ← 边框变为主色
│                            │     外部光晕
└────────────────────────────┘
```

### ARIA 状态

```html
<!-- 按钮加载状态 -->
<button aria-busy="true" aria-label="正在分析，请稍候">
  <span class="spinner" aria-hidden="true"></span>
  分析中...
</button>

<!-- 展开/收起 -->
<button aria-expanded="true" aria-controls="panel-1">
  展开详情
</button>

<!-- 选中状态 -->
<div role="tab" aria-selected="true" tabindex="0">
  语音分析
</div>

<!-- 禁用状态 -->
<button aria-disabled="true" disabled>
  提交
</button>
```

## 🎨 视觉规范

### Header 区域

**尺寸**: 高度 72px，固定顶部  
**背景**: 白色 + 底部阴影 (shadow-sm)  
**Z-Index**: 50

**Logo 区域**:
- 图标: 40x40px，渐变背景 (primary → secondary)
- 文字: "多模心探"，text-xl，gradient-text

**导航链接** (桌面端显示):
- 字体: text-base, font-medium
- 颜色: text-secondary，hover:text-primary
- 间距: gap-8

**用户头像**:
- 尺寸: 40x40px
- 形状: rounded-full
- 边框: 2px solid primary

## 📱 响应式适配

### 移动端 (< 640px)

- Hero: 单列，文字居中
- 轮播: 单卡片显示，滑动切换
- 特性: 单列堆叠
- 统计: 2x2 网格
- 导航: 汉堡菜单

### 平板端 (640px - 1024px)

- Hero: 两列，比例 1:1
- 轮播: 双卡片显示
- 特性: 2x2 网格
- 统计: 4列等分

### 桌面端 (> 1024px)

- Hero: 两列，比例 5:7
- 轮播: 三卡片显示
- 特性: 4列等分
- 统计: 4列等分

## 🎬 交互动效

### 页面加载动画

```
Header: fadeInDown, duration: 0.5s, delay: 0s
Hero 标题: fadeInUp, duration: 0.6s, delay: 0.2s
Hero 副标题: fadeInUp, duration: 0.6s, delay: 0.3s
Hero 按钮: fadeInUp, duration: 0.6s, delay: 0.4s
Hero 插图: fadeIn, duration: 0.8s, delay: 0.3s
```

### 滚动触发动画

```
Carousel: fadeInUp, trigger: scroll into view
Features: stagger fadeInUp, delay: 0.1s each
Stats: countUp animation for numbers
```

### 悬停效果

```
导航链接: color transition 0.2s
模块卡片: translateY(-8px) + shadow-lg, duration: 0.3s
按钮: opacity 0.9 + shadow, duration: 0.2s
```

### SVG 动画

```
脑波动画: path morphing, 3s infinite
数据流: stroke-dashoffset, 1s infinite
心跳: scale pulse, 1s infinite
状态点: opacity pulse, 2s infinite
```
